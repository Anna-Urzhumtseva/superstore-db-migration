# 🗃️ Миграция и нормализация данных Superstore

Проект по переносу данных из плоской Excel-таблицы (9 994 записи) в нормализованную реляционную базу данных SQLite.  
Демонстрирует навыки **ETL**, **проектирования БД**, **SQL** и **Python**.

---

## 📌 Цель

- Устранить дублирование и избыточность данных.
- Спроектировать нормализованную структуру (3-я нормальная форма).
- Реализовать ETL-пайплайн для загрузки данных.
- Получить готовую базу для аналитики и BI.

---

## 🧩 Структура базы данных

База состоит из 9 таблиц с внешними ключами:

| Таблица | Описание | Количество записей |
|---------|----------|-------------------|
| `Product` | Справочник товаров | 1 894 |
| `Customers` | Клиенты | 793 |
| `People` | Менеджеры | 4 |
| `typeShip` | Способы доставки | 4 |
| `Addresses` | Адреса клиентов | 4 910 |
| `Orders` | Заказы | 5 009 |
| `OrderDetails` | Позиции заказов | 9 993 |
| `dateShip` | Даты и способы доставки по заказам | 5 009 |
| `Returns` | Возвраты | 800 |

Связи реализованы через внешние ключи (FOREIGN KEY).

---

## ⚙️ ETL-процесс

1. **Extract** — данные извлечены из Excel с помощью `pandas`.
2. **Transform** — дедупликация, создание суррогатных ключей (`ProductCode`, `AddressesID`, `ShipID` и др.), разделение на сущности.
3. **Load** — загрузка в SQLite с сохранением целостности данных.

---

## 🛠️ Инструменты

- **Python** — `pandas`, `sqlite3`, `openpyxl`
- **SQL** — сложные запросы с `CTE`, `ROW_NUMBER()`, `LEFT JOIN`
- **DBeaver** — визуализация схемы и контроль
- **VS Code** — среда разработки
